# ScarlettEmu — The Most Useless Xbox Series S Emulator for macOS

> ⚠️ **DISCLAIMER / ОФИЦИАЛЬНЫЙ ДИСКЛЕЙМЕР:**  
> **Это абсолютно юзлесный эмулятор Xbox Series S.**  
> GTA 6 тут не запустится. Коммерческие зашифрованные игры из магазина Microsoft тоже не запустятся (расходимся).  
> Проект написан ради фана, науки, экспериментов и изучения низкоуровневых систем: как работают современные HLE-эмуляторы (в духе **shadPS4**), как устроен перехват вызовов GameOS и как транслировать консольный DirectX 12 в **Apple Metal** на чипах Apple Silicon (M1/M2/M3/M4/M5).

## 💡 Что этот «юзлесный эмулятор» реально умеет?

Несмотря на статус «юзлесного», под капотом у него работает настоящий сквозной пайплайн эмуляции:

1. **🧠 10 ГБ унифицированной памяти GDDR6:**
   * Менеджер виртуальной памяти (`mmap`) выделяет честные 10 гигабайт адресного пространства под архитектуру Xbox Series S.
2. **📦 PE32+ (AMD64) Загрузчик:**
   * Парсит настоящие 64-битные бинарники под процессор AMD Zen 2 (DOS-заголовки `MZ`, секции `.text`, `.rdata`, `.idata`, RVA-адреса).
3. **⚡ Динамический перехват импортов (IAT) и HLE-трапы:**
   * Автоматически находит вызовы библиотек `KERNEL32.dll` и `d3d12_x.dll`.
   * Патчит таблицу адресов импорта (IAT) на специальные машинные инструкции-ловушки (`0x0F 0x0B` / `UD2`).
4. **⚙️ x86-64 Диспетчер инструкций (Interpreter):**
   * Выполняет машинный код процессора AMD Zen 2, обновляет регистры общего назначения (RAX, RCX, RDX, RSP, RIP) и флаги `RFLAGS`.
5. **🎮 Консольный Direct3D 12.X ➔ Apple Metal:**
   * Ловит вызов `D3D12CreateDevice` из консольной библиотеки `d3d12_x.dll`.
   * Открывает нативное окно macOS Cocoa (`NSWindow` 1280x720).
   * Компилирует шейдеры на языке **Metal Shading Language (MSL)** и выводит в 60 FPS культовый 3D-треугольник в фирменных неоновых цветах Xbox!

## 🛠 Сборка и запуск на Mac

### Требования:
* macOS (Apple Silicon M-серии)
* Xcode Command Line Tools (`clang++`, `make`)
* CMake 3.20+

### Сборка:
```bash
# 1. Сборка эмулятора
cmake -B build -S .
cmake --build build
```

### Запуск встроенного теста:
```bash
./build/scarlett_emu
```

### Запуск настоящей тестовой демки (с 3D-графикой Metal):
```bash
./build/scarlett_emu samples/demo_game.exe
```

## 🧪 Как скомпилировать свою демку под Scarlett

В комплекте идет пример демки (`samples/demo_game.c`), которая вызывает `VirtualAlloc`, создает устройство через `d3d12_x.dll` и завершает процесс:

```bash
# Генерация библиотеки импорта для d3d12_x.dll
x86_64-w64-mingw32-dlltool -d samples/d3d12_x.def -l samples/libd3d12_x.a

# Компиляция демки под архитектуру AMD64
x86_64-w64-mingw32-gcc -O1 -nostartfiles -e EntryPoint \
    -o samples/demo_game.exe samples/demo_game.c \
    -Lsamples -ld3d12_x -lkernel32
```
